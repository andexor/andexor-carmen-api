# Andexor Carmen API

The back-end services for Andexor Carmen, the Customer Relationship Management (CRM) system for Andexor Network. FastAPI on Cloudflare Python Workers with D1 and R2, served at `carmen.andexor.net/api/*`.

- Requirements: [`PRD.md`](PRD.md), governed by the master PRD in `andexor-carmen-main`.
- Conventions: [`CLAUDE.md`](CLAUDE.md).
- Constitution: `.specify/memory/constitution.md`, copied from `andexor-carmen-main`.

Work follows Spec Kit. The feature backlog is section 13 of the PRD.
